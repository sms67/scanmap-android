# اسکن‌مپ سازمانی — نسخه اندروید (ScanMap Organizational)

اپلیکیشن بومی اندروید برای **نقشه‌برداری داخلی با راه‌رفتن + اسکن واقعی وای‌فای (Site Survey)** —
ساخته‌شده با Kotlin، بدون نیاز به سرویس‌های گوگل، با رابط فارسی راست‌به‌چپ مطابق طراحی مرجع.

## امکانات

- **سه نمای همزمان و زنده**: دوربین (CameraX) + نقشه 2D از بالا (شبکه متریک) + مدل 3D با پرسپکتیو ۶۰ درجه
- **موقعیت‌یابی با سنسورها**: Rotation Vector (قطب‌نما) + شمارش گام با شتاب‌سنج (آستانه تطبیقی) → ردیابی متریک (dead-reckoning)
- **ساخت نقشه**: ضبط دیوار هنگام پیمایش (+ثبت گوشه)، رسم اتاق با لمس (مساحت خودکار)، دیوار آزاد، تنظیم موقعیت با لمس برای اصلاح انحراف
- **وای‌فای واقعی**: اسکن WifiManager، تخمین فاصله با مدل Log-distance (n قابل تنظیم)، تخمین موقعیت AP با **حداقل مربعات** از نمونه‌های مسیر، رنگ پین بر اساس کیفیت سیگنال (عالی/خوب/متوسط/ضعیف)
- **طبقات و پروژه‌ها**: هر طبقه نقشه و APهای خودش؛ ذخیره خودکار پروژه‌ها
- **خروجی‌ها**: PNG نقشه، PNG مدل 3D، عکس دوربین، **OBJ بر حسب متر برای 3ds Max**، CSV لیست APها، JSON پروژه

## نصب APK

1. آخرین APK امضاشده را از [بخش Releases](../../releases) دانلود کنید (فایل `ScanMap-v1.0-signed.apk`).
2. در اندروید: تنظیمات → امنیت → اجازه نصب از منابع ناشناس.
3. فایل را نصب کنید. (امضای نسخه‌های بعدی یکسان است؛ به‌روزرسانی مستقیم نصب می‌شود.)

## نکات استفاده

- برای اسکن وای‌فای: مجوز **موقعیت مکانی** را بدهید و **سرویس موقعیت (GPS) دستگاه روشن** باشد (الزام اندروید).
- ابتدا در تنظیمات، **طول قدم** را کالیبره کنید (پیش‌فرض ۷۲ سانتی‌متر).
- گوشی را هنگام پیمایش صاف و ثابت نگه دارید؛ برای محیط‌های بزرگ چند مسیر متقاطع بپیمایید تا تخمین موقعیت APها دقیق‌تر شود.
- ورود OBJ در 3ds Max: `File → Import → Geometry → OBJ` (واحد: متر، محور Z رو به بالا).

## بیلد از سورس

- روی هر push به `main`، گیت‌هاب اکشن APK امضاشده را می‌سازد و در Release با تگ `latest` می‌گذارد.
- بیلد محلی: `./gradlew assembleRelease` (JDK 17)

## امضا (Keystore)

- فایل: `keystore/release.keystore` (PKCS12، alias: `scanmap`)
- رمزها در `gradle.properties` (`IM_STORE_PASS` / `IM_KEY_PASS`)
- ⚠️ برای به‌روزرسانی‌های بعدی همین keystore را نگه دارید تا امضا تغییر نکند. برای امنیت بیشتر می‌توانید رمزها را از ریپو حذف و به‌عنوان GitHub Secret تعریف کنید.

## ساختار سورس

```
app/src/main/java/com/scanmap/org/
├── MainActivity.kt    # اتصال UI، تب‌ها، حالت‌ها، خروجی‌ها
├── Dialogs.kt         # طبقات/پروژه‌ها/AP/خروجی/راهنما
├── SensorEngine.kt    # قطب‌نما + گام‌شمار → موقعیت متریک
├── WifiEngine.kt      # اسکن واقعی WifiManager
├── TopView.kt         # نمای 2D از بالا
├── PerspectiveView.kt # مدل 3D (۶۰ درجه)
├── CamHud.kt          # اطلاعات روی تصویر دوربین
├── ObjExporter.kt     # خروجی OBJ (3ds Max) و CSV
├── Model.kt           # مدل داده + JSON
└── GeoUtils.kt        # مساحت، ساده‌سازی مسیر، مثلث‌بندی
```
